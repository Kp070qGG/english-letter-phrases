## 💡 使用建议

- 高级句式是"点睛之笔"，每篇穿插 2–3 个即可，切忌通篇堆砌。
- 先保证时态、人称、主谓一致不出错，再考虑炫技。
- 每天选 1 类文体仿写 100 词左右，检查语气、逻辑与语境是否匹配。
