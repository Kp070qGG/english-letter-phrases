## 💡 使用建议

1. **先搭骨架，再嵌亮点**：高级句式是"点睛之笔"，不是越多越好。先按 开头 → 主体 → 结尾 搭好逻辑，再把高级表达放进关键位置。
2. **分类记忆**：每种信件至少掌握 3 组开头 + 3 组主体 + 2 组结尾，考试时自由组合。
3. **替换克制**：一个句子里最多替换 1-2 处，选择最符合语境的那个，而不是最长的那个。
4. **每日仿写**：每天选 1 类信件，用模板写一封 100 词左右的完整信件，检查语气、逻辑与语境是否匹配。
